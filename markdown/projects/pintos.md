## PintOS

A multi-phase operating systems project built on the PintOS instructional
kernel. Across the phases I implemented:

- **Threads**: priority scheduling and synchronization primitives.
- **User programs**: argument passing, system calls, and process control.
- **File system**: extensible files, subdirectories, and a buffer cache.

The project was a deep dive into the boundary between hardware and software, and
a lot of careful debugging with GDB.
